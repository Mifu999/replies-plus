# 1.1.0
- Added **exact comment & reply dates**, read straight from the timestamp RobTop's server sends with each comment (`Date Display` setting).
- Added **reply IDs** on cells (`Show Reply IDs` setting).
- Added a **Reply Info popup**: tap the date line for the full ID, local + UTC timestamps, account ID, likes, level ID and a copy button.
- The root comment now keeps its **percent** and its **moderator chat colour**.
- Replies from deleted or unregistered accounts now show `- (ID: x)` instead of a blank name.
- Added node IDs to every part of a reply cell, so other mods can hook into them.
- Bumped the project to C++23, as Geode v5 requires.
